## 三个坑（全 VERIFIED-RUN）
1. **memory server 无视 GOOSE_PATH_ROOT**：goose-mcp 的 `choose_app_strategy` 硬编码 `%APPDATA%\Block\goose`（源码 lib.rs APP_STRATEGY：top_level_domain/author/app_name 全 "Block"/"goose"），etcetera 直接解析 AppData。config envs、wrapper cmd set、bash export 都改变不了它。→ 解法：**NTFS junction**（`mklink /J` 免管理员）：AppData memory 目录 → `conf/goose/config/memory`。bootstrap.ps1 1c 段自动建；卸载=删 junction（一条 rmdir，不伤便携数据）。
2. **config envs 传给 stdio 子进程不可靠**：spawn .cmd 也需 `cmd /c` 包装（CreateProcess 不直接执行 .cmd）——wrapper 方案保留（给未来需要 env 的扩展用）。
3. **PowerShell 5 无 BOM 中文脚本解析损坏**：bootstrap.ps1 必须 UTF-8 **BOM** + CRLF（否则中文字节按 GBK 误读导致诡异 Null 错误）。
