# 2026-08-23 s09 — P16 模型/供应商体系（按正确产品语义重构）

## 用户纠正的语义（本轮核心）
模型配置三层：
1. **服务商**：多家 OpenAI 兼容（地址+Key），档案化（providers.json v2：{name,host,key,models[],active}）
2. **每家的可用模型**：⟳ 从 /v1/models 拉取 → **勾选清单**（默认不全选）→ 勾中的进入员工可选池
3. **会话中切换**：顶栏 = 全部档案勾选池聚合（显示"家 · 模型"），即时切换

## 实现
- **桥**：spawnAcp 工厂（env 按激活档案生成）+ `hotRestartProvider()`（跨供应商切换 = 杀 acp 子进程换 env 重启，会话 DB 保留，UI 重开旧会话即恢复上下文）+ `switch_model` 路由（同家 `session/set_config_option`；跨家热重启）+ providers v1→v2 自动迁移。
- **UI**：顶栏模型池跨家聚合+搜索+当前高亮；设置页 = 服务商档案管理（新建/编辑/启用/删除）+ 拉取→勾选清单实时入池（每勾一个即存）+ 测试连通；切换反馈文案小白化（"正在切换服务商…几秒"）。
