## 用户报"会话中切不了模型"诊断结论
机制本身**真实生效**——llm_request 日志实证 set_config_option 后请求 model 字段变更；跨家热重启后提问也正常回复。用户遇到的是三层可用性问题（全修）：
1. **Key 被保存流程清空**（严重）：UI 保存档案时空 Key 覆盖原值（UI 端列表脱敏不回传 key，桥端 update 直接 Object.assign 把 key 抹成空）→ Authentication error。修：桥端 update 时空 key 字段不覆盖。此 bug 才是"切换后模型不可用"的主因。
2. 未开对话时点切换静默失败 → 现在自动开新对话并完成切换。
3. 切换反馈用 ⚠ 错误样式 + 无下一步指引 → 独立 info 样式（绿底），跨家切换明确说"点左侧对话继续，内容都在"。
