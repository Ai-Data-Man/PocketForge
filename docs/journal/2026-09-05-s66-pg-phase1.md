## 事故记录：dev 栈静默宕机 + 验证陷阱（收尾时发现）
- 沙盒轮结束后的"dev 栈恢复"实际未生效（runas wrapper pause 静默不执行——该轮工程师自记的坑，自己也被坑）；后续一切"bridge 200"验证均被 **Bash 环境沙盒代理的假响应**骗过：栈宕时 curl 打 127.0.0.1 任意端口仍得恒定 2.0s 的 200（代理连接超时回退），node 直连/netstat/IAB 才是真话（ECONNREFUSED/无监听）。主控用 node+netstat+IAB 三方确认宕机后，runas wrapper 重拉恢复（node 实证 8790/5432 真监听、stats 15ms）。
- 教训入库：**验证 127.0.0.1 服务生死必须用 node 直连或浏览器，禁止采信 Bash curl 的 200**；连带影响：9router 复测研究员已收到纠偏（本地端点禁用 curl）。
- 真实检索基线（宕机恢复后 node 实测）：2038 条消息 LIKE 检索 0-3ms（冷扫 149ms）——/api/search 当前完全无感，阶段三触发器维持"近 1 万条"不变。此前 2.0s 读数全系假响应。
