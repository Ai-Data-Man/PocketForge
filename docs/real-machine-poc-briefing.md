# 真机 POC 护航须知（v0.9.10 行为速查，一页纸）

> 用途：在她电脑上做 POC 时对照。分步操作清单见 docs/poc-真机检查单.md（15 分钟版）与 docs/真机护航清单.md（D 序列完整版）；行为变化的完整说明见 docs/v0.9.10-release-notes-draft.md。
> 本页只回答一个问题：**看到的哪些现象是正常的**。预期不符时拍照 + 拷 `data\logs\` 发回，不用自己排查。

## 开机自检预期
- 双击「启动数字员工」→ 黑窗口出现启动字样 → welcome 页自动弹出 → 聊天窗就绪、左上角绿点亮起。
- 首启比以往多等约 10-20 秒：后台第一次初始化数据库，只发生这一次。
- 进程管理面板里应看到 **pg**（数据库进程，v0.9.9 起新增）与其余常驻进程；nats 显示 Not Ready 但功能正常 = 已知显示滞后，不算失败。
- 「停止数字员工」后任务管理器应无 process-compose.exe / postgres.exe 残留（本版之前它们从未被真正停掉，已修）。

## 首任务预期：弹卡 = 正常
- 让它做真实任务（写文件 / 查数据 / 做表）时，可能先弹一张大白话卡片，说它想执行什么——这是新版安全默认「重要操作问我」，不是卡死。
- 怎么批：**✅ 允许这次** / **✅ 以后都允许**（同类不再问）/ **🚫 这次不行**。
- 卡片 60 秒没人选 → 自动「这次不行」，任务停在原地（可恢复；它绝不会无人放行）。回来再点一下就能继续。
- 想让它一口气干完：顶栏「工作模式」切「自动干活」。

## 四挡工作模式怎么选（顶栏下拉，选了会记住）
| 档位 | 行为 | 适合 |
|---|---|---|
| 重要操作问我（默认） | 动您的东西前先问；只看看、查查不问 | 日常推荐 |
| 自动干活 | 全自动，做完汇报 | 熟练后、批量活 |
| 每步都问我 | 每个动作都确认 | 最稳，敏感环境 |
| 只聊天不动手 | 只对话，不碰文件和网页 | 纯问答 |

## 技能 / 插件装取入口（v0.9.10 s74 起的新布局）
- **技能**：聊天窗下方工具条 **🧩** 打开，里面分两个标签：
  - 「**我的技能**」= 它已经会的（可搜索）；
  - 「**＋ 添加新技能**」= 技能市场（先点「先看内容」过一眼 → ⬇ 添加，立刻生效）。来源徽标：**🌐** 市场装的 / **✹/✍** 自己攒的 / 无标 = 出厂自带。「技术设置：技能从哪进货」折叠区给懂技术的人用，平时不用打开。
- **插件**：聊天窗 **🧠 管理小 forge** → 「🔌 插件」标签：安装后**重启数字员工**生效；停用/卸载同处（页底的「插件目录（技术）」同样是给懂技术的人的）。
- 同名安装有保护：自己攒的技能不会被市场同名的悄悄覆盖。

## 找旧对话 / 归档
- 侧栏顶部常驻「**💬 对话 | 📦 归档 N**」切换钮：归档的对话都在「📦 归档」页里，带搜索和翻页——不用再滚到列表最底下找。

## 出问题怎么报
- **📮 一键上报**：聊天窗左侧栏下方「📮 反馈问题」→ 自动生成报告文件、文件位置已复制 → 把文件发给懂电脑的人（报告自带「小forge自己看到的毛病」自查节，比描述症状快）。
- **🩺 先自查**：点快捷指令「🩺 做个体检」（或直接对它说「做个体检」），多数小毛病它自己会找到。

## 「看起来像坏了，其实是有意为之」清单
| 现象 | 真相 |
|---|---|
| 弹出权限卡，任务停下来等 | 新安全默认：重要操作先问您，点了才动 |
| 卡片 60 秒没人理，任务自己停了 | 自动选了「这次不行」——不会无人放行；再点一下继续 |
| 界面/日志里少了一些内置工具 | 四组用不到的平台工具被收起（更快更省），不是坏了 |
| 它做一件事之前不问、做另一件之前问 | 「重要操作问我」只问写和动，只读的照做不问 |
| 任务里一次命令失败，接着又自己好了 | 设计内自愈重试 |
| nats 面板显示 Not Ready | 探活显示滞后，功能正常 |
| 首启慢 10-20 秒 | 首次初始化数据库，只此一次 |
| welcome 页没弹 | 机器没设默认浏览器；手动开 forge\data\welcome.html |
| 技能页/侧栏/数据面板跟以前长得不一样 | v0.9.10 界面重新归置：技能分「我的/添加」两标签、归档有专属入口、数据表分组带说明——东西没丢，换了该在的位置 |
| 数据表旁边写着「（还没说明——点开看结构）」 | 老表没有说明数据；它以后建的新表会自动带一句人话说明 |
