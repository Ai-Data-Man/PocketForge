## 给用户的人话版

### 最重要的变化：它现在「先问再做」（新默认）
- 以前默认「自动干活」：它动手前不问，做完才告诉您。本版起默认改为「**重要操作问我**」：凡是要动您的东西的动作——执行命令、新建/改写文件、删改数据库内容、打开或点击网页——都会先弹一张大白话卡片问您，**您点了它才动**。只看看、查查（不动任何东西）的事不问，直接做。
- 卡片 **60 秒没人理会，它会自动帮您选「🚫 这次不行」**，任务就停在原地等您回来——它绝不会趁没人看着偷偷干活。停住不等于弄坏，回来再点一下就能继续。
- 想要原来的省心习惯：聊天窗口顶栏「工作模式」下拉切到「**自动干活**」——一键切回，选择会记住。

### 技能货架更丰富了
- 技能市场新增一个来源（**baoyu 开源技能库，21 枚新技能**，说明是中英双语的，用中文搜更容易命中）。
- 每个技能现在都标来源：**🌐** = 从网上技能库装的（标注来自哪家）；**✍** = 在这个小 forge 里自己攒的；无标 = 出厂自带。
- 装同名技能不会悄悄覆盖：您自己攒的技能受保护，市场同名的会被拦下先说清楚；万一安装中途出岔子，旧版原样还在。

### 看不见但有用
- 它手里的内置工具精简了一批（四组用不到的平台工具收起来了）：界面看不出来，但任务更快、更省。
- 「安全护栏」说明页的文字与实际行为对齐了：页面上说的是什么，实际做的就是什么。

### 修了什么（界面 24 处中的主要几条）
- 消息里的 **加粗** 文字此前完全显示不出来——已修复
- 服务商页的勾选框被拉成 440px 宽的长条（内测点名的那个）——已修复
- 弹窗现在都能用 ✕ 或 Esc 关闭；模型下拉不再点一下弹两下
- 长回复时页面自动跟着滚到底（您往上翻看历史时它不打扰）
- 深色模式下按钮文字看不清——对比度已修正
- 它忙时「停止」按钮不再被挤出屏幕；工具解释气泡不再被屏幕边缘裁掉

## 升级必读（v0.9.8 / v0.9.9 存量用户）

### 装完后第一眼：多了「权限卡」是设计，不是坏了
1. 多出来的权限卡是**新的安全默认**——它动您的东西前先问，您点了才动。
2. 卡片 60 秒没人理会，它自动选「这次不行」——**绝不会没人看着就偷偷放行**；任务停住可恢复，回来再点一下就继续。
3. 想要原来的省心习惯，顶栏「工作模式」**一键切回「自动干活」**，选择会被记住。

补充一句：如果您之前**手动**切过模式，升级后保持您手动选的那挡；没动过的才落到新默认「重要操作问我」。

### 升级路径
- v0.9.8 的「离线升级」按钮有缺陷（上传被拦截，v0.9.9 候选已修）——v0.9.8 用户升级路径只有两条：①设置里配好 GitHub 源走在线自动更新；②手动：停旧版 → 换程序目录（保留 data/）→ 启动。
- 升级完成后请做一次**干净重启**（双击「停止数字员工」→ 再「启动」）。
- **v0.9.9→v0.9.10 升级复演实测（2026-09-06）**：升级链路本身走通（325MB 真包、sha 校验、差量、重启、健康检查全链）；data/ 下用户数据（对话/文件/上传物）完好。**但「设置类」用户态在存量升级路径会被重置**：能力开关、已装插件（mcp-*）、长期记忆库会回到新模板默认（详见下条与「给内测者」段）。
- **升级前请手动备份 `forge/conf/goose/config/` 整个文件夹**（复制到别处即可），升级完成后如发现能力开关/已装插件/记忆不对，停栈后把它放回原位再启动——放回的内容会被启动合并保留（合并路径已沙盒实证）。这一步的本版限制与自动保全计划见「给内测者」段。

### 离线升级通道（本版新增，已落地并沙盒实证）
- 「离线升级」现在是**两步向导**：第 1 步选安装包 .zip，第 2 步选校验文件 .sha256——桥端自算自验（sha256 实算比对 + zip 魔数预检 + 字节数对账），配对通过才亮「开始离线升级」；任何校验失败都人话提示且不留垃圾文件，安装包传对了就不必重传（1c4a1e0 + c8a1103）。
- **注意**：两步向导的 .sha256 上传只在**新桥（v0.9.10）**上可用——从 v0.9.9 及更早版本升级时，旧桥不收 .sha256 文件（API 白名单拒，实测），请把校验文件**手动放到** `data/updates/staged/`（与 zip 同名）再点开始，或改走 GitHub 在线通道。
- ~~升级不再丢配置~~ → **复演证伪并修正（见升级路径第 3/4 条）**：新 runner 的 PROTECTED 保全只对「由 v0.9.10 执行的后续升级」（v0.9.10→未来）生效；v0.9.8/v0.9.9→v0.9.10 这一代由旧版 runner 执行（运行中不换代码），无法保全——桥端升级前自备份设计入 v0.9.11。
