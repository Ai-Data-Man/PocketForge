## 用户可感变化
- **对话列表**：左栏活跃对话超 30 条自动分页（第 N/M 页翻页器），搜索框对话/归档两视图常驻——原来「还有 X 个更早对话没显示」的死提示删除（fa07896）。
- **消息「取回修改」**：消息下方操作条原「重发」（点击即原样重发）改为「取回修改」——把原文装回输入框等你改完再发，不再误触烧调用（a3b47d0）。服务商报错卡的自动重发帮助保持原样（s50e 韧性路径，行为不变）。
- **@ 引用**：输入框提示文案改为「输入 @ 引用文件或数据表」——@ 菜单里本来就能引用数据库表，此前提示漏说（9101f5f）。
- **看图（see-image）修复+升级**：上一版技能指向的 tools/vision.js 根本不在安装包里（坏了）；现在工具随包（bin/vision.js），并支持换看图模型：对小 forge 说「换个看图模型」，它会列出可用模型让你挑，选定后持久保存（FORGE_VISION_MODEL），下次直接用（ff02cb5；qa 返工加固 set-model 注入防护 17c6e89）。注意：旧默认 myopencode/glm-5.2 线路在网关侧已失效（404），新装种子改 deepseek-v4-flash（04d9ad6/ccaaf48）。
- **安全护栏说明归位**：设置面板里只有两张静态说明卡的「安全护栏」标签页删除；四档工作模式的说明移到顶栏工作模式选择处（悬停可见、切换时弹一句人话）——护栏本体（审批卡）不变（a26499b）。
- **报错更人话**：模型服务出错时不再把英文内部错误原样透出，按「Key 没配好 / 服务商暂时不通 / 这一轮没完成」三档提示（ff03b03）。

## 用户可感变化（s77 批，2026-09-08~10）
- **我的提示词库（📖）**：输入框旁新入口——把常用话术「说一遍就留住」：面板里可保存当前输入框、改名编辑、删除（二次确认），带搜索和分页；点条目插到输入框光标处，**不会自动发送**。
- **输入框按 Tab 唤起提示词搜索**：话到嘴边想起存过——按 Tab 弹出迷你搜索，↑↓ 选、Enter 插入（不发送）、Esc 退出；与 @ 引用、/ 命令菜单互斥不打架。
- **✨ 提示词优化**：输入框旁新按钮——把粗话术一键变规格（消歧/补输出格式/补受众约束/收窄范围/去口语冗余），**先预览再决定**：「用这版」替换进输入框可继续编辑，「不用」原文一字不动；改动逐条明示，绝不新增你没提过的要求。
- **白话解释重写（大修）**：修复前解释器从未见过工具真实输出（工具卡输出区也自上线从未显示过内容），产出的解释靠猜、常与事实相反。现在：工具卡输出区真实显示命令输出；解释点名真实工具名/文件名/版本号/报错关键词，技术名词保留并附一句括号解释，失败时按「失败→错在哪→可能原因→你要做什么」四段讲清；不知道的就明说不知道。
- **消息撤回重写（真撤回，不是追加）**：自己发的每条消息新增「撤回重写」——撤回该条及其后所有来回（历史与模型上下文一起回滚），原文放回输入框改完再发，历史显示=改写后的样子，无追加痕迹。撤回前自动留备份（每会话最近 3 次，tools/rollback-restore.js 可恢复）；对话进行中会礼貌拒绝。
- **升级前备份失败警告不再阴魂不散**：此前注入失败后警告残留到重启（fc42e81）。

## 缺陷修复
- **P1 删当天最新会话→之后新对话全部「秒回空」**（s75 修复的回归，research/18 断点①）：goose 会话号按当日最大号+1 分配，删行使号段回退复用已关闭的会话号，桥曾把错误当成功。现在：报人话错误 + 自動换新会话重发一次（单次救援，ff0a092；畸形帧崩溃向量封堵 2534bb1；救援去重/断连守卫 1ddff47/d539ebb）。
- **升级安全**：升级执行前桥自动备份 conf/goose/config/ 与 data/config/ 到 data/backups/pre-upgrade-<时间>/（保留 3 份，幂等，失败不阻断）——「存量升级丢配置」从手动备份步骤变成机制兜底（43eff60）。
- **升级器加固**：runner 落盘日志+五检查点心跳+20 分钟总超时自动回滚（停栈段超时回滚已实证触发）；下载双超时封死「静默挂死」窗口（c425d1c/5b837b2）。
- **定时任务漂移守卫**：桥对源配方↔注册副本只读对账，漂移时 UI 人话告警+暂停恢复前置确认（cf5f250；手册改「任务协议」）。
- **permission.yaml 运行时副本停追踪+升级保护**：git 只追踪种子模板（conf/templates/permission.tpl.yaml），bootstrap 首启 copy-if-missing（空文件/缺块自动留档补种，55d5776/649d464/fc75240）；升级差量永不删改它（PROTECTED，qa 实证「每次升级都会重置 judge 缓存」后拍板）——goose 学习的审批条目升级后存活。
- 报错卡「点重发」指代失效、错误卡英文透传、s50f 存量测试红、报告探针跨午夜必红（测试钟表 bug）、e2e 套件首红即中止不可观测——全数修复（1285b46/ff03b03/2534bb1/c4b8ce6/f148671）。
