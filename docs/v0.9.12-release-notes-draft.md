# PocketForge v0.9.12 发布说明（草稿，发版时机待用户拍板）

更新日期：2026-09-13（s78 工作会话产出）。基线：e2e-chat 57/57 + fuzz 150/150（基线自 v0.9.11 的 55/150 升档，新增竞态/重试断言节）。

## 给使用者的话（正文用）

这次更新主要修了三件你可能遇到过的事：

1. **服务商配置再也「配不上去」的问题修好了**——以前添加新的服务商档案后，页面会悄悄把表单切回旧的那家，导致模型列表拉错地方。现在表单会一直停在你正在编辑的那家。
2. **线路坏了会主动告诉你**——聊天窗口顶部新增提醒条：模型服务商联系不上、或你用的模型已被服务商下架时，打开页面就能看到，点按钮去换，不用再「发消息石沉大海」。中转站 09-12 一夜下架模型名的实事故就是这个功能救场的场景。
3. **发消息偶尔会悄悄落错对话的 bug 修好了**——刚打开应用的两秒内点进旧对话，消息可能发进一个空对话且无任何提示。现在有代际守卫，不会串。

另外：大白话解释更稳了（模型偶尔「没说出话」会自动重试一次）；工具卡和权限卡里的长密钥改为打码显示；给妻子的使用说明补齐了常用话术（Tab）、✨优化、消息三按钮、顶部提醒条的说明。

## 内核升级：goose v1.46 → v1.50

数字员工内核 goose 升级到 v1.50.0（十面回归全绿：定时任务/权限/会话编号/消息撤回手术面全部逐项验证）。升级中发现并适配了一处上游行为变化（v1.50 对标准输入关闭更敏感，定时器守护进程改用管道保持方式，新旧版本兼容）。v1.50 捆绑的官方内置技能（web-search 网页搜索、goose-doc-guide 官方文档指引）经裁决从产品裁剪：前者在无外网搜索环境的企业机上会诱导联网安装依赖，后者面向开发者且在目标机上无法工作。裁剪方式为「同名护栏桩」——不影响日后从技能商店显式安装同名技能（用户选择优先）。

### 给 IT/懂电脑的人：杀毒软件说明（EDR）
- 本包无数字签名。Windows Defender 的「低流行度+新文件」信誉规则可能对新解压的程序弹提示或自动隔离——这是对新文件的通用信誉检查，不是检出恶意行为。处理：在 Defender 的「保护历史」里还原并允许即可；公司电脑可按包根目录新增的 **SHA256-EXE.txt**（54 个程序的完整哈希清单）向 IT 登记白名单。
- 从 v0.9.11 自动升级到本版只会写约 20 个文本文件，全部程序文件字节不变（哈希清单可核），不会引入新的程序哈希。
- 若公司电脑启用了 AppLocker/WDAC 应用控制（默认阻止用户目录运行程序），需 IT 放行后再使用。
