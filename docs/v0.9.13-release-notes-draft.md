## 给使用者的话（正文用）

这次更新主要解决四件你可能遇到或迟早会遇到的事：

1. **放到中文文件夹也能用了**——以前把整个文件夹解压到带中文的路径（比如「桌面\数字员工」）再双击启动，窗口里会冒出奇怪的报错、数据库起不来。现在启动时会先用一句人话提示你换个纯英文/数字路径（如 D:\PocketForge），不再出现看不懂的失败。启动窗口里的中文乱码也一并修好。
2. **小 forge 搭的应用有了自己的家（🚀 小应用）**——以前让它给你搭一个应用（比如一个能打开的网页小工具），搭完就没地方看了：不知道开没开着、不知道从哪儿打开。现在 ⚙️ 面板多了一页「🚀 小应用」：每个应用一行，绿灯就是在跑，点「打开看看」直接进它的页面；没有网页入口的应用会老实说「它在后台做事」，不放打不开的链接。
3. **升级不会再把自建应用弄丢**——以前升级版本会把你已经注册的应用配置悄悄删掉。现在应用配置和你的数据一样受保护，升级后应用自动回来。
4. **出厂默认模型名更新**——模型服务商已下架旧默认模型名，本版出厂默认换成在售的新名；如果你的线路出现模型下架，页面顶部提醒条会直接告诉你怎么换。

另外：换电脑/改文件夹名后「小 forge 记住的事」失联的问题修好了（失效的内部链接会自动重建）；安装包里不再混入开发机的临时文件。

## 变更明细（技术面）

### 修复（s86，冷启编码审计 P1-P7，docs/runbooks/2026-09-14-cold-start-codec-audit.md）
- P1 控制台乱码：启动器 `chcp 65001`（UTF-8 生产者 × CP936 控制台错配根治；与 P2 成套落地，单独任一改法实测失败）
- P2 中文安装路径 `.cmd` 误解析：bootstrap 生成的两个包装脚本（memory-mcp/pg-init）改 `%~dp0` 纯 ASCII 模板 + CRLF（不再向 .cmd 注入含非 ASCII 的绝对路径）
- P3 非 ASCII 安装路径预检：启动器在 bootstrap 前检测 FORGE_ROOT 含非 ASCII 字符 → 人话提示换路径并退出（中文提示经 base64 通道输出，启动器语法保持全 ASCII 可解析）；PG 上游对非 ASCII share 目录的限制在预检层拦截，不再出现 initdb 自删数据目录
- P4 `%APPDATA%` memory junction 悬挂自愈：守卫从 Test-Path 改为「Junction 且 Target 存在」双条件，改名/搬迁后自动重建，静默失忆面闭合
- P6 出厂默认模型 deepseek-v4-flash → deepseek-v4.1-flash（bootstrap 种子+幂等补键/config.yaml/forge-router.json/goose-config.tpl.yaml 四处；旧名 2026-09-12 已被服务商下架）
- P7 使用说明启动标记与实际输出对齐（`[PocketForge] starting...`）

### 新增（s87，应用运行面板，裁决 docs/verdicts/2026-09-14-app-runtime-panel.md）
- ⚙️ 管理面板第 7 tab「🚀 小应用」：apps/*.yaml 注册清单 × process-compose 运行状态只读观察面——状态徽章（✅运行中/⏹已停/⚠️出错/下次启动自动带起）+ 人话名/说明 + 注册时间 + 来源对话回链 + 唯一动作「打开看看」（URL 三层来源：建账 meta > readiness_probe 合成 > 诚实降级「没有网页，它在后台做事」，不猜端口不放死链）
- 桥 GET /api/apps（+171 行）：自研最小 YAML 行级解析器（零新依赖）；pc `process list -o json` 状态合并（is_running/exit_code 布尔数值映射，不依赖状态字符串）；listenPorts 实听端口并集（≤8 次/请求护栏）；pc 不可达时诚实降级「状态未知」不炸端点
- 建账协议：hints 应用注册协议第 5 条「建账留痕」——apps/*.yaml 首行 `# forge-meta:` 注释行（description/url/created_at/source）；模板占位行复制即继承；真模型活体验证 agent 无额外提示自发落账
- **升级保护**：update-runner PROTECTED += 'apps/'——升级差量对用户已注册应用目录零删除（此前每次升级即删光用户 app，独立缺陷级修复，与面板同批）
