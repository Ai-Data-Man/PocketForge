# PocketForge v0.9.15 发布说明

更新日期：2026-09-18（s95-s97 工作会话产出）。**发布包**：`PocketForge-20260918-v0.9.15.zip`（sha256 见随包 `.sha256`）。基线：e2e-chat 61/61 + fuzz 190/190；**从零安装专项**：本版周期共 10 个出厂沙盒轮次（s95 iat1-6 四轮 + s97 iat7-13 六轮），每轮抓到的缺陷当日修复、次轮复验。

## 这次修了什么（给使用者的话）

1. **它搭的应用，现在能直接管了**——「🚀 小应用」页每个应用有「⏹ 停止 / ▶ 启动」按钮；它停的应用会告诉你「下次启动时自己回来」，不会一声不吭消失。应用多了也不怕：按「运行中 / 已停 / 出错了」一键筛选，找「哪个出错了」一下就到。
2. **定时任务页一样好找**——任务多了可以按「排着的 / 暂停的」筛选，翻页找旧任务。
3. **第一次打开更省心**——双击「启动数字员工.cmd」后，黑窗口会直接打出网址、自动弹出聊天窗口（不用再找第二个文件）；欢迎页也是等服务真正准备好才出现，不再一闪而过打不开。
4. **「帮我做个小应用」这条路彻底修通了**——以前让它搭一个带网址的常驻小工具，走到「上线注册」这步会静默失败或悄悄断线（界面上显示失败，其实东西已经搭好了一半）。这一版连挖六轮，把从「写好程序」到「上线给你网址」之间的六处断点全部修掉，最后实测从零安装一条龙成功：它搭好应用、注册上线、告诉你网址和用法，电脑重启后应用还会自己回来。
5. **启动更安静**——安装后头几分钟的内部整理（数据库初始化、首次注册登记）现在在欢迎页弹出之前就悄悄做完；整理期间正常使用聊天也不会被打断。
6. **备份更可靠**——以前偶发「启动时的数据备份悄悄没做成」（内部两个步骤抢同一个文件），现在会等待重试，备份不再缺席。
7. **停止更果断**——「停止数字员工」遇到卡住的情况，最多等 15 秒就自动强制收尾，不会再出现「停止中」永远停不下来。
8. 并入 v0.9.14 全部内容（首次配置修复/代理绕行/做过的东西返工等，见 v0.9.14 说明）。

## 技术明细（s95 能力域 + s97 修复族）

### 能力域信息架构与启停（s95，裁决 docs/verdicts/2026-09-16-capability-ia-bloat-startstop.md）
- 词汇分职：出厂自带=「本事」（🧠 纯三开关）；后来学会的=「🧩 技能」；装的新本事=「🔌 插件」（tab 内启停钮归位）。
- 清单规模内建制：技能来源四态 chips；🚀小应用/⏰定时 补内建分页+维度筛选；🗄️数据 行级分页 30/页；apps/sched/mcp 搜索域补齐。R2 规范升级：无上限增长清单强制「分页+搜索+结构维度」三件套（AGENTS.md §7）。
- POST /api/apps 启停三道闸（注册表白名单+基础设施 deny-list+Origin 校验）；应用日志折叠子区（📋 最近日志）。
- 聚合器守卫：apps yaml 声明基础设施键→跳过+人话告警（防栈毁）。

### 热注册缺陷族 F-3~F-12（s95 轮1-4 + s97 轮1-6，全部当日修复+复验）
- **F-3/F-6（s95）**：agent 热注册命令文件集不全→整栈重启→回合孤儿化卡死 14h；根因链三段取证（research/31），修=hints 教 wrapper 单命令+会话中断终态兜底（桥补发错误帧+前端收口）。
- **F-7** wrapper 环境自备：pc update 按调用方环境重渲染全部配置，agent 缺端口/密钥变量时空值漂移（对照组 pg 死透）。
- **F-8** 应用模板教法：裸拼 pc 命令（崩溃族配方）改教 wrapper 单命令。
- **F-9** wrapper ROOT 归一化：`..\..` 未解析脏串 vs 启动器干净路径→31 处路径漂移→全表重启；**同时破案 s95 遗案**：轮 3/4 的「restarts=0」是 pc update 换血后计数器归零的假象（诚实观测锚=pc.log 的 ACP initialized 计数）。
- **F-10** 教法补时长纪律：冷启收尾链排队致注册 >60s，agent 自设 60s 超时掐死正在成功的注册→hints 教 timeout≥300 秒。
- **F-11** 种子真值收敛：bootstrap 从服务商档案现读 agent 三键（原缺省死地址被桥改写造成「启动导出值≠文件值」漂移）+退化档案镜像桥写值形态+`forge-root.txt` 规范形（pc 路径对比大小写敏感，源码+活体双证）。
- **F-12 根治**（research/34 源码定案）：process-compose v1.122.0 `project update` 存在 **Vars 类型漂移**（PC_REPLICA_NUM int→JSON 往返 float64，DeepEqual 判不等）→**守护生命周期内第一次 update 必全表重启**。修法=启动收尾（就绪后、开窗前）静默自跑一次收敛 update，把首更重启消耗在无人对话窗口；出厂时间线铁证：收敛 08:40:20（开窗前）→开窗 08:40:25，收敛后注册纯新增零重启。上游 issue 草稿已备（docs/research/34a，待用户提交）。
- 会话中断兜底：任何原因的回合中断（含桥重启），前端收口终态（清忙碌+卡面 settled 化），不再有永远转圈的回合。

### 启动器与停止（s97 主线2+支线）
- `conf/open-when-ready.ps1` 就绪门控：TCP+healthz 双探（240s 预算）→打印网址+中文提示→首启欢迎页（3s 改名保 s50 语义）→Edge --app 聊天窗（与手动入口逐参数同款，缺 Edge 回落默认浏览器）→超时只打印人话不弹窗。启动收敛段（F-12 根治）内嵌其中。
- 停止脚本 wedge 态有界化：down 客户端分离执行+15 秒预算→强制收尾（实测 21.2s 收口 vs 修前永久挂起）。
- faucet-rawsql 锁容忍：busy_timeout+退避（与供给 oneshot 并发不再失败，备份链整链保通）。

## 给 IT/懂电脑的人

- 本包无数字签名。Windows Defender「低流行度+新文件」可能对新解压程序弹提示——按包根 **SHA256-EXE.txt**（全部 exe 哈希清单）向 IT 登记即可。
- **代理环境**：agent 出网自动对活跃服务商主机直连（NO_PROXY 注入）；探测通但代理开着时仍有提示条，供排查参考。
- 管理员账户双击启动已支持（自动降权）；非 ASCII 安装路径仍会被预检拦截（PG 上游限制）。
- process-compose 首更全表重启为上游已知问题（详见 docs/research/34），本版已通过启动收敛自动规避；上游修复后可移除该段。
