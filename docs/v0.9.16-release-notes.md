# PocketForge v0.9.16 发布说明

更新日期：2026-09-25（s98 尾段–s102 工作会话产出）。**发布包**：`PocketForge-20260925-v0.9.16.zip`（sha256 见随包 `.sha256` 与文末校验段）。基线：e2e-chat 62/62 + fuzz 225/225 + ui-logic 56 + ia-logic 34 + semantics-r5 38 + capeditor 141 + modelcaps 43 + w2-preset 15 + think 35 + think-grad 27 + proxythink 30 + llmproxy-xlate 10 + w1-effort 14；从零安装专项：本版周期出厂沙盒 iat14–iat24 共 11 轮系列验证（每轮缺陷当日修复、次轮复验），v0.9.16 发版门=最终包全新解压冷装冒烟全绿。

## 这次修了什么（给使用者的话）

1. **「思考力度」真的生效了**——聊天窗口上方、模型名字旁边的「思考力度」，现在按每个模型官方支持的档位来显示（比如「快一点 / 深想 / 尽全力想」），选哪档就真按哪档跑：选深一档更准也更花时间，随时点回来。以前这个开关在不少线路上是「看着切了、其实没变」，这一版从界面到线路再到模型层层打通（包括常用的中转线路），档位带来的是真实的思考量差异。调不了快慢的模型会诚实写着「想多深它自己定」。
2. **⚙️ 设置重新分了家**——左边一列三块：「🔌 大模型连接」（连哪家、地址和钥匙）、「🎨 外观」（白天黑夜、颜色、字号）、「🩹 关于与升级」（版本新旧）。模型清单能直接搜索，也加了「＋添加模型」；以前出厂预填的那个内网中转地址不再默认带上（用得到的自己配，配法不变）。
3. **模型的本事，认错了你能改**——每个模型「能不能看图、上下文多大、思考分几档」，现在来自一份逐条核对了官方文档的底表（75 个模型、14 家厂商，每条都标着出处）。清单里每个模型旁边写着「（官方）」「（你改的）」还是「（猜的）」；它要是把某个模型认错了（比如明明能看图却写不能），点旁边的「配置」改对就行——改哪项哪项就记住你的，没改的继续跟着官方走；改过想改回官方说法，点「恢复官方默认」一键回。
4. **它的家当，词都说清了**——出厂长的叫「自带的」，后来装的外接叫「工具」，学会的做法叫「手艺」；手艺攒到一百多条也不怕：不用的先停用（档案还在，随时开回来），还能勾一批一起停/开。
5. **东西多了也好翻**——所有清单的「每页 N 条」你自己调（选一次，以后处处照办，也能一页看全）；「整理」模式进了工作区、归档对话和记忆：没用的旧文件夹勾一勾一起删、收起来的旧对话整批清、每一类记忆一键全忘。
6. **数据面板扛得住了**——表攒到上千张也不卡：先看清单，点开哪张才取细节，搜索能搜到全部表名。
7. **做报表能直接用库里的表**——「📊 帮我做张报表」除了选文件里的表格，也能直接选它存在数据库里的数据表（每张标着有几条）。
8. **第一次启动更稳了**——修掉了一个偶发的「首次启动时数据库/定时调度悄悄没起来、而且永远不会自己好」的坑（两个同族问题一起根治）；撞上也会在启动收尾自动补跑，黑窗口里能看到「补跑」字样，不用重装。
9. 并入 v0.9.15 全部内容（小应用启停面板/首次启动引导/上线注册六连修等，见 v0.9.15 说明）。

## 技术明细（按域）

### 思考力度全链路（s98 llm-proxy → s101 官方原生参数 → s102 扩写器+审计修复）
- **s101 定案**（裁决 docs/verdicts/2026-09-23-thinking-native-params-official-presets.md）：深度档=模型官方原生参数（research/40/42/43 = 45 模型官方规范 + 41 官方端点实测推翻「参数死透」）；官方预置表 `conf/model-presets.json` 取代名字启发式（71→75 条 14 厂，每条 source_url+verified，(host,model) 二元组匹配——同模型跨平台能力不同）；字段级 `user_fields`（改哪项哪项转手动=ZCode 语义）；家族换模型机制降为兜底默认关；「恢复官方默认」一键（反单向棘轮）。
- **s102 扩写器**：THINK_KEY_WRITERS 增 `enable_thinking`/`EnableThinking` 布尔族（官方机读表依据）；五族（thinking/thinking_budget/thinkingConfig/reasoning/thinking_strategy）因值形态跨厂分裂**有据不实现**（统一 writer 必对某厂 400，诚实降级落空不发）；「关思考」对布尔门族只发 `enable_thinking=false`（官方 none→False 语义，QA 复审抓出方向反错后返工闭环）；归一改「域内值优先」（原生档不再被别名表改值——qwen3.8 选轻档静默得重档的缺陷根治）；预置表全量 71 条审计修复三处 P2（glm-5 正则集合错/claude 默关族默认档矛盾/归一顺序）+卫生批（底稿出处标注、4 新条目、kimi-k3 阿里二元组）。
- **中转侧**：glm 系经 9router 的参数透传在用户侧 fork 已修（3ed55d53，zai-claude 线写 output_config.effort + flash 能力条目补齐，四臂生产验证 token 单调分离）；PocketForge 侧零改动直接受益。其它中转若丢参数=界面照常可切、上游丢弃不受控（诚实降级）。
