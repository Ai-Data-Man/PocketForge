# S107 微裁决：pg 不可达的妻子可见信号

裁决 pf-pm 2026-10-02。输入：journal s107 §七（当日沙盒 pg 全日不可达、妻子面零信号实录）+ STATE backlog 两条关联项（pg 孤儿 5432 / 可见信号缺失）。证据分级随条标注；真机 pg 坏频率未知，按现有证据裁。

## 问题

谁在痛：**已有数据表的用户**，pg 挂时打开 🗄️数据 tab 或 📊报表向导。频率：真机未知（仅数据点=dev/沙盒环境事故：s91 孤儿家族、s107 全日、RCA39 冷启 bug 史）；低频但命中即持续到人工干预。不解决的代价：她看见「表全没了」=**数据丢失误读**——本产品对妻子最坏的失败形态，且无自助出路、无恢复预期。

关键事实：
- **F1（VERIFIED-RUN，research/39 arm1a）**：pg 停时 `/api/db/overview` 返回 `{ok:true,services:[]}`——桥的 `ok:false` 分支（chat.tpl.html loadDbUI「数据库没在跑，看不到明细。」）对 pg-down 形态是**死分支**，仅 faucet 硬死才触发。
- **F2（VERIFIED-DOC）**：`tblMiss` 标记已随 overview 响应携带（chat-bridge.tpl.js:2593）；✨做过的东西 tab 已消费同款诚实降级行（madePaint :2306/:2309；qa s83d F-1 定性=**误导性空态必须修**）——🗄️数据 tab 未消费（dbPaint 只读 truncated）。同洞未修=既有先例下的不一致，非新判断。
- **F3（VERIFIED-DOC）**：桥 s90 pg 降级文案（「没连上数据库…」）唯一妻子面出口=升级窗格 `upd-warn`（:655）——正常视野不可见。
- **F4（VERIFIED-DOC）**：🗄️ tab 顶部「数据存储」三态点（s73）对象=对话统计存储，文案是安抚+零动作（「数据还是齐的…自动切回」），不解释下方清单为何空。
- **F5（VERIFIED-DOC）**：向导 dbOverview null→只显文件组，静默降级=设计内（:1043 注释）。
- F6：pg 不碰聊天主链（SQLite）；pg 坏=数据功能降级，非产品死亡。

## 选项与裁决

**修，选 A 收窄版（两处一行级消费者，零新探活、零桥改、零 faucet 改）：**

1. **🗄️数据 tab**：消费既有 `tblMiss`（并对齐 `ok:false` 分支文案），「库里的数据」清单顶部一行：**「数据库这会儿没连上，表暂时列不出来。数据没丢。重启数字员工试试；还不行就先放一放，回头再看。」**——零术语（「数据库」=既有家族用词，:2271/:2306 先例）；「试试」对冲孤儿形态（重启未必救，不过度承诺）。
2. **📊报表向导**：dbOverview 为 null 时选择器区一行注：**「数据库这会儿没连上，表暂时选不了；文件不受影响。」**

- **拒 B（健康条加 db 态）**：健康条=主链（LLM 服务商）健康，全局挂载因聊天必经；pg 不碰主链。低频非主链事件加常驻家族成员违背「ok 态零视觉」经济性，且 healthz 本就不盖 pg（s107 方法论⑤）需新探活管道——成本与频率倒挂。
- **拒 C（不修）**：被 qa s83d F-1 自家先例否决（同族误导性空态在 ✨ 已修）；妻子误读=数据丢失，代价上限极高，修法两行。
- **不取纯 D**：向导静默缩窄同族（她上周建的表从选择器消失无解释），同一 null 判断上补一行边际成本近零。

## 边界

- 信号源只用既有载荷（tblMiss / ok:false / 客户端 null）；客户端 60s 缓存滞后可接受（made tab 同款）。
- 不动「数据存储」三态点（s73 裁决域）；机制不进配置面（§9.4），无条件文案。
- **非目标**：B 全局健康条；pg-down 根因（孤儿 5432=独立 backlog）；healthz 扩盖 pg（工程师观测面，cold-surface 门条目）；净装空清单歧义（无先前期望=无害，不覆盖——s107 场景本身无害，有害的是「有表变没表」）；@ 菜单同类静默缩窄（妻子主路径=向导，有使用证据再裁）。
- 不确定标注：「已注册服务+pg 停」时 faucet `db list` 是否仍列服务（推断：list 读 faucet SQLite config store 不碰 pg；arm1a 零服务不能判别）——见验收 3。

## 验收口径（§8 沙盒纪律）

1. 臂一（有表+pg 停）：注册过 ≥1 服务的沙盒停 pg → 🗄️ tab 降级句在场、向导=文件组+一行注、控制台零错。
2. 臂二（pg 健康）：零视觉差（无降级句，向导双组齐全）。
3. 臂一同时实证该形态 overview 实际返回（ok:false 或 tblMiss）——**两分支须渲染同一句**（实现据此对齐 :2271 旧文案）。
4. 回归：chat.tpl.html UI 面 → e2e-chat 全量 + ui-logic。
5. 零术语检查：新文案无 pg/端口/进程词。

优先级 P3（低频、非主链、命中误读代价高）；批次=下次触 UI 会话捎带，不单开。
