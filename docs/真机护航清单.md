## E. 采集项

1. EDR：产品名/版本；每条告警截图+时间点+步骤号；静默隔离对比（包文件数）。
2. 耗时：启动→桥就绪（首启含杀软首扫/二启）；D2 端到端秒数；C1 配 key 耗时。
3. 卡点：任何与沙盒不一致处，按「步骤号+现象+截图」记录，宁多勿漏。
4. 统计自证：回程前 forge\data\ 统计文件存在且 upstreamByKind 有 unauthorized ≥1（D8 后）。
5. 环境特征：代理软件名、EDR 对 localhost 出网反应、IE-mode 浏览器存在性。
