# 看图（调用视觉模型）

## 何时用
- 用户说"看看这张图/截图"
- 你做完网页后想核对视觉效果（配合 browser 工具截图）

## 步骤
1. 截图（浏览器场景）：用 browser 工具的截图能力拿到文件，或让用户给路径。
2. 调视觉模型（glm-5.2 已验证支持看图）：
   用 shell 执行：
   `<包内node> %FORGE_ROOT%\bin\vision.js <图片路径> "你的问题"`
   （若 %FORGE_ROOT% 为空，安装目录见系统提示/工作区路径，用它代替。）
   ——问题要具体："布局是否正常/数字是多少/有什么异常"。
3. 把视觉模型的回答转述给用户（说人话）。

## 换看图模型（首次使用或看图报错时）
看图报错说"尚未设置视觉模型"，或报模型不存在/不能看图时，按顺序走：
1. 查当前用的模型：`<包内node> %FORGE_ROOT%\bin\vision.js --get-model`（未设置时会提示）。
2. 列服务商可用模型：`<包内node> %FORGE_ROOT%\bin\vision.js --list-models`（一行一个模型名，不含密钥）。
3. 用人话向用户转述候选并给建议（glm-5.2 已验证能看图，可优先推荐），等用户选定——不要替用户拍板。
4. 用户选定后执行：`<包内node> %FORGE_ROOT%\bin\vision.js --set-model <选定的模型名>`，会回复"视觉模型已设为 X，立即生效"。
5. 向用户复述设好了，然后重新看图。设置长期有效，下次不用再设。

## 硬边界
- 永远不要读取、打开或输出 data\secrets.env 的内容——里面存的是密钥。看图和换模型都只用上面的命令，永远不需要碰这个文件。

## 坑
- 不是所有模型都能看图：kimi-k2.7-code 不行（会瞎猜）；glm-5.2 可以。不确定就先拿 1x1 红色图问"什么颜色"验证。
- 路径用绝对路径；中文问题加引号。
