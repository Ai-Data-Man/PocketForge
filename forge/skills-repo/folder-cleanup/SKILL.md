# 工作区清理

## 步骤
1. 列出工作区全部文件，按名字分组：同名的 -v2/-v3/带旧日期 的算一组。
2. 每组只留最新一个，其余列出来给用户看："这些旧版本可以删吗？"
3. 用户点头后再删（删除前走版本管理存一版，随时能找回）。
4. 汇报：删了几个、腾出多少空间、保留了什么。

## 坑
- 附件（.forge 里标记的）和用户明确提过的文件绝对不动。
- 只清理当前工作区，别碰其他对话的文件。
- 拿不准是不是旧版本，就问，不要猜。
