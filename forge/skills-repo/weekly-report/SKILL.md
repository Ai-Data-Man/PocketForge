# 周报生成

## 步骤
1. 确认数据来源：问用户数据在哪个表/文件，或从工作区里找最近修改的 xlsx/csv。
2. 用 faucet_query 或读文件拿到原始数据。
3. 统计本周（周一至今）的关键数字：总数、比上周增减、最大/最小项。
4. 用 gen-xlsx.js 生成 `周报-YYYY-MM-DD.xlsx` 放到工作区（表头：指标/本周/上周/变化）。
5. 聊天里只说三句结论：总体情况、最大的变化、需要注意的一件事。

## 坑
- 数据里有空值先过滤，别让"比上周 +NaN%"出现在报表里。
- 上周同期数据找不到就明说"上周无对比数据"，不要编数。
